# Siko AI — Flutter MVP

Siko is an Arabic-first smart assistant prototype focused on:

- French learning in Arabic
- American/British English learning in Arabic
- Text chat with Siko
- Voice input (device speech recognition)
- Text-to-speech replies
- Custom assistant name and owner name
- Robot avatar by default
- User-selected image avatar (human, animal, character, object, etc.)
- Basic local persistence

## What is already included

This repository contains the Flutter application source and the UX structure. The app runs in **Demo/Offline AI mode** without any API key. In this mode, chat replies come from a small local rule-based engine so you can test the UI immediately.

An optional Gemini REST integration is also included. Add the API key in `lib/config/app_config.dart` only on a personal/dev build. Do not commit a real API key to a public repository.

## Requirements

- Flutter 3.44+ / Dart 3.12+
- Android SDK installed
- Android 10+ device recommended
- VS Code with Flutter and Dart extensions

Flutter currently supports Android deployment from API 24 upward; this project targets Android 10+ (API 29+) for the app experience.

## First setup on Windows

The source archive intentionally keeps native Android scaffolding generated by Flutter out of the zip so the project stays clean and version-friendly. From Windows, run the included setup script once:

```powershell
.\tools\setup_windows.ps1
```

or double-click:

```text
setup_windows.bat
```

The script runs `flutter create` to generate the native platform scaffolding and adds microphone permission required by speech recognition.

Then:

```bash
flutter pub get
flutter run
```

## Optional Gemini mode

Open:

`lib/config/app_config.dart`

and set your personal development API key. The app will automatically use Gemini when a non-empty key is configured; otherwise it remains in Demo/Offline mode.

The REST endpoint/model are isolated in `lib/services/ai_service.dart` so they can be replaced later without changing the UI.

## Voice

The app uses the device speech-recognition service through `speech_to_text`, and the Android Text-to-Speech engine through `flutter_tts`. Availability depends on the installed Android speech/voice engines and supported locales.

## Avatar system

Default mode: animated vector-style robot drawn in Flutter (no external image required).

Custom mode: the user can pick any image from the phone — a human face, animal, cartoon, logo, object, or anything else. The app adds a subtle speaking/listening animation around the image.

Important: the current MVP does **not** perform true facial lip-sync on arbitrary uploaded faces. That is planned as a later AI/avatar module.

## Avatar roadmap

- Phase 1: built-in animated robot + any gallery image.
- Phase 2: avatar emotions (happy, thinking, surprised, listening, speaking).
- Phase 3: lip-sync driven by TTS timing.
- Phase 4: optional AI-generated animated avatar provider. This phase should be treated as an optional cloud feature because true arbitrary-image talking avatars are not a lightweight offline Android feature.
